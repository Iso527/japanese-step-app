# 日语小步学 v0.3

零基础、手机优先、轻量 PWA。核心目标：每天约 10 分钟，通过小课、听音、情景任务和间隔复习逐步获得日常交流能力。

## v0.3 改进
- 新手首次打开引导，降低认知负担
- 今日 10 分钟目标
- 学习地图与明确的下一步
- 课程完成后自动建立复习卡
- 简单间隔重复：1/3/7/14/30 天
- 待复习提醒
- 五十音平假名/片假名听音辨认 5 题小测
- 课程与复习数据本地保存
- 使用系统日语 TTS，不打包大量音频
- 无第三方 JS 框架、无图片、无后端
- 可离线缓存基础页面

## 使用
直接打开 `index.html`。支持浏览器的情况下可通过“添加到主屏幕”作为 PWA 使用。
